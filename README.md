# Sinaps

Локальный голосовой ассистент для Windows. Всё считается на твоей машине:
ни один байт аудио не уходит в сеть, API-ключи не нужны, платить не за что.

**Статус:** Alpha 1.0. Этапы 0–3 закрыты: аудио-контур, понимание команд и
управление ПК, интерфейс с треем, история и настройками. Не готово: таймеры,
напоминания, заметки, погода и поиск — это v1.

---

## Быстрый старт

```
git clone <адрес> Sinaps
cd Sinaps
setup_sinaps.bat          ← двойной клик, дальше ждать
run_sinaps_silent.bat     ← запуск
```

Первый запуск занимает 15–40 минут и качает ~5,5 ГБ (модели и библиотеки).
Всё остальное помещается в git: репозиторий весит меньше двух мегабайт.
Подробности установки — ниже.

## Что работает

**Голос**
- 🎤 Распознавание речи — faster-whisper, локально, на GPU если есть
- 🔇 Границы фраз — Silero VAD, не ждём фиксированные 5 секунд
- 🔊 Синтез речи — Silero TTS v5, 5 русских голосов, ~150 мс на фразу
- ⌨️ Текстовый ввод как полноценная альтернатива голосу
- 🛑 Прерывание: заговорил — ассистент замолчал
- 🔇 Если микрофон молчит, ассистент **скажет об этом вслух**, а не промолчит

**Интерфейс**
- 🖥 Значок в трее с индикатором состояния: слушаю / думаю / говорю / пауза
- 📜 Окно истории с поиском по всем прошлым разговорам
- ⚙️ Окно настроек: микрофон, голос, кнопка активации, модель распознавания
- 🕒 Автозапуск вместе с Windows

**Понимание — 35 команд, 9 навыков**
- ⏰ Время, дата, день недели
- 🚀 Открытие и закрытие программ, файлов, папок
- 🔈 Громкость, mute, медиаплеер
- 📊 Состояние системы: процессор, память, диск, батарея, время работы
- 🖥 Окна: список, переключение, закрытие, свернуть всё
- 📋 Буфер обмена, скриншот, яркость
- ⚡ **Питание — только с голосовым подтверждением**

## Требования

- **Windows.** Linux и macOS не поддерживаются: `platform/` заточен под
  Windows, управление ПК на них не заработает.
- **Python 3.12** — строго. На 3.13 и 3.14 нет wheels у `ctranslate2`, поэтому
  `faster-whisper` там просто не установится.
- **~6 ГБ свободного места** под модели и библиотеки.
- Микрофон — опционально. Без него ассистент работает через текст.
- Видеокарта — опциональна. Без неё распознавание идёт на CPU и медленнее.

## Установка

Нужен **Python 3.12**. Вручную ничего ставить не надо:

```
setup_sinaps.bat
```

Скрипт сам найдёт подходящий Python, создаст `.venv`, поставит зависимости,
скачает модели и проверит микрофон. Один раз.

| Что | Размер | Куда |
|---|---|---|
| torch, CUDA, PySide6, sounddevice | ~3,5 ГБ | `.venv\` |
| faster-whisper `large-v3-turbo` | ~1,5 ГБ | `models\` |
| Silero TTS v5 (5 русских голосов) | ~140 МБ | кэш torch |
| Silero VAD | ~3 МБ | кэш torch |
| **Всего** | **~5,5 ГБ** | |

Повторный запуск безопасен: всё, что уже скачано, повторно не качается.

Докачать недостающее или просто проверить:

```powershell
.\.venv\Scripts\python -m sinaps setup           # докачать
.\.venv\Scripts\python -m sinaps setup --check   # проверить, ничего не качая
.\.venv\Scripts\python -m sinaps setup --model small   # взять модель поменьше
```

### Если нужна модель поменьше

По умолчанию `large-v3-turbo` — лучшее качество, но и самый вес:

| Модель | Размер | Замечание |
|---|---|---|
| `tiny` | 75 МБ | черновое качество, для проверки |
| `base` | 145 МБ | |
| `small` | 461 МБ | быстро, без GPU |
| `medium` | 1,5 ГБ | нужна GPU |
| `large-v3-turbo` | 1,5 ГБ | лучшее качество, GPU 8+ ГБ — по умолчанию |

Без видеокарты удали из `requirements.txt` строки `nvidia-cublas-cu12` и
`nvidia-cudnn-cu12` — будет работать на CPU.

## Запуск

```powershell
.\run_sinaps_silent.bat          # с треем, без консоли — основной режим
.\run_sinaps.bat                  # с консолью, для отладки
.\run_sinaps.bat setup            # установка / докачка
.\run_sinaps.bat selftest         # проверка окружения
.\run_sinaps.bat check-mic        # проверка микрофона
.\run_sinaps.bat hotkeys          # проверка клавиш и кнопок мыши
.\run_sinaps.bat devices          # список аудиоустройств
.\run_sinaps.bat commands         # список всех команд
.\run_sinaps.bat try "открой блокнот"   # проверить фразу, ничего не выполняя
.\run_sinaps.bat listen           # один цикл: послушать и ответить
.\run_sinaps.bat listen --file tests\fixtures\open_notepad.wav
.\run_sinaps.bat record           # записать 10 с с микрофона в WAV
.\run_sinaps.bat evaluate         # сравнить модели STT на ваших записях
.\run_sinaps.bat speak "Привет"    # просто озвучить текст
.\run_sinaps.bat benchmark        # замер задержек
.\run_sinaps.bat metrics          # статистика задержек
```

### Режим с треем

`run_sinaps_silent.bat` запускает ассистента без окна консоли. Значок в
области уведомлений показывает состояние:

| Цвет | Что происходит |
|---|---|
| серый | микрофон открыт, ждёт активации |
| зелёный | слушает |
| жёлтый | думает |
| синий | говорит |
| красный | ошибка |
| тусклый | пауза |

Меню значка: **Пауза**, **Озвучка ответа**, **История**, **Настройки**,
**Очистить историю**, **Выход**. Двойной клик открывает историю.

> Windows 11 прячет часть значков под стрелкой `^`. Если значок Sinaps
> пропал — перетащи его мышью на панель задач обратно.

**История** (`data/history.db`, SQLite) хранит реплики локально. Срок хранения
задаётся в настройках, по умолчанию 30 дней. Это не кэш — единственная копия
переписок.

**Автозапуск** включается в «Настройки → Распознавание → Запускать вместе с
Windows». Пишется в `HKCU\...\CurrentVersion\Run`, без прав администратора;
отключается там же или в «Диспетчере задач → Автозагрузка».

### Как будить ассистента

| Действие | Кнопка |
|---|---|
| Открыть окно прослушивания | боковая мышь **«вперёд»** (mouse5) |
| Говори, пока держишь | боковая мышь **«назад»** (mouse4) |
| То же с клавиатуры | `Ctrl+Space` |

После активации — 8 секунд на фразу. Клавиатура работает одновременно с
мышью: если софт мыши съел боковую кнопку, остаётся запасной способ.

Не срабатывает кнопка — проверьте отдельно: `.\run_sinaps.bat hotkeys`.
Подробности — [`docs/HOTKEYS.md`](docs/HOTKEYS.md).

### Команды внутри работающего ассистента

```
/help          справка
/devices       аудиоустройства
/config        текущая конфигурация
/metrics       задержки
/history       история диалогов
/reload        перечитать config.yaml
/quiet on|off  включить/выключить озвучку
/quit          выход
```

Всё остальное — реплика ассистенту.

> **Про `.bat`:** файлы `run_sinaps.bat`, `run_sinaps_silent.bat` и
> `setup_sinaps.bat` намеренно написаны **только латиницей**. `cmd.exe` читает
> `.bat` в системной кодировке (866/1251), а не в UTF-8, поэтому кириллица
> внутри батника разрушает разбор команды: `%ERRORLEVEL%` съедается, `>nul`
> распадается, и скрипт уходит в бесконечный цикл ошибок «не является
> внутренней или внешней командой». Весь русский текст — внутри Python.

## Если микрофон молчит

Самая частая проблема, и самая непонятная: ассистент не падает, не
предупреждает и просто не слышит. Причина почти всегда одна — **Windows
выбрал не тот вход**.

По умолчанию система берёт микрофон материнской платы (разъём сзади
корпуса). Если туда ничего не воткнуто, а наушники подключены как
**только выход** (гарнитура без микрофона, или микрофон не в разъёме),
уровень сигнала будет −70…−50 дБ, и каждая фраза уйдёт в никуда.

**Проверь, что показывает система:**

```powershell
.\run_sinaps.bat check-mic
```

Если в конце `FAIL: сигнал слишком тихий`, а VAD показывает 0% речи —
вход не тот. Какие устройства есть в системе:

```powershell
.\run_sinaps.bat devices
```

Задать нужный вход явно — в окне настроек (вкладка «Звук» → «Микрофон ввода»)
или в `data/config.yaml`:

```yaml
audio:
  input_device: 17      # индекс из вывода команды devices
```

**Проверить микрофон по-крупному** — проговорить что-нибудь и посмотреть
уровень. Речь в норме даёт пик **−35…−20 дБ**. Тише −60 — микрофон молчит.

### Если микрофон слышен, но тихо

```yaml
stt:
  min_dbfs: -60.0       # по умолчанию -50
```

Но сначала попробуйте поднять громкость записи в Windows: настройки →
Система → Звук → Ввод. Чаще всего хватает этого.

### Если ассистент выдумывает фразы

Whisper на тишине не молчит, а сочиняет правдоподобное — «субтитры»,
«спокойная музыка». Это его устройство, а не ошибка настройки:

```yaml
stt:
  min_confidence: 0.25   # живая речь 0.53–0.92, выдумки 0.00–0.06
  min_dbfs: -50.0
```

- Не слышит голос → понизьте `min_dbfs` до `-60`.
- Слышит, но отвечает «не расслышал» → понизьте `min_confidence` до `0.15`.
- Для отладки — `min_dbfs: -120.0`, `min_confidence: 0.0`.

Подробности — `ARCHITECTURE.md`, раздел 10.

### Если запущено несколько копий

Две копии делят один входной аудиопоток Windows, и речь разрывается на
обрывки. Вторая сама откажется стартовать, но проверить стоит:

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe' OR Name='pythonw.exe'" |
    Select-Object ProcessId, CommandLine
```

Остановить всё:

```powershell
Get-Process python,pythonw -ErrorAction SilentlyContinue | Stop-Process
```

Не запускайте `run_sinaps.bat` и `run_sinaps_silent.bat` одновременно: первая
для работы вручную, вторая — для автозагрузки.

### Если микрофона нет вообще

Ассистент не падает, а переходит в текстовый режим и предупреждает об этом.
Форсировать явно:

```powershell
.\run_sinaps.bat --text-only
```

## Настройка

`data/config.yaml` создаётся автоматически при первом запуске. Главное:

```yaml
audio:
  input_device: null      # null = системный микрофон по умолчанию
  pre_roll_ms: 500        # миллисекунд записи ДО начала речи

stt:
  engine: faster_whisper
  model: large-v3-turbo   # tiny | base | small | medium | large-v3-turbo
  device: auto            # auto | cuda | cpu
  compute_type: int8_float16
  min_confidence: 0.25    # ниже — считаем галлюцинацией, не команду
  min_dbfs: -50.0         # тише — в модель не идём

tts:
  engine: silero
  voice: ''               # пусто — голос по умолчанию
  speed: 1.0              # 0.5 … 2.0

vad:
  threshold: 0.5          # чувствительность
  silence_ms: 600         # пауза, считающаяся концом фразы

wake:
  mouse_button: mouse5    # активация мышью
  push_to_talk: mouse4    # удержание
  hotkey: ctrl+space      # запасной способ с клавиатуры
  listen_timeout_s: 8.0

privacy:
  local_only: true        # требование проекта: сеть запрещена
  keep_history_days: 30   # 0 — не хранить историю
```

Чувствительнее микрофон: снизьте `vad.threshold` до `0.35`.

## Какие команды понимает ассистент

Полный справочник — [`docs/КОМАНДЫ.md`](docs/КОМАНДЫ.md). Для каждой команды
указано полное имя намерения, реальные фразы, слоты и пометка
`[ТРЕБУЕТ ПОДТВЕРЖДЕНИЯ]` для опасных действий.

Файл **генерируется из кода**, поэтому не может устареть:

```powershell
.\run_sinaps.bat commands --out docs\КОМАНДЫ.md
```

Проверить конкретную фразу, ничего не выполняя:

```
фраза                        намерение              слоты
который час                  time.now               -
открой блокнот               apps.open              name=блокнот
выключи компьютер            power.shutdown         - [опасное]
сделай абстрактную фигню     -- не найдено --
```

### Замер задержек

Ключевая метрика — `response`: от конца фразы до первого звука ответа.

```
  стадия          n      p50      p95     mean      max
  -----------------------------------------------------
  vad_end         5    4.219    4.672    4.035    4.672   ← конец речи
  stt_done        5    0.313    0.453    0.347    0.453   ← распознавание
  response        5    0.313    0.469    0.350    0.469   ← ЗАДЕРЖКА ОТВЕТА
  total           5    4.625    5.141    4.385    5.141   ← включая речь

Ответ быстрее 1.6 с: 100% диалогов
```

`vad_end` и `total` большие потому, что тестовый файл проигрывается в
реальном времени — это длительность речи, а не задержка системы. Требование
«ответ за 1–2 секунды» выполняется с трёхкратным запасом. Повторить:
`.\run_sinaps.bat benchmark`.
