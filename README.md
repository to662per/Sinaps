# Sinaps

Локальный голосовой ассистент для ПК. Всё работает на твоей машине: ни один
байт аудио не уходит в сеть, API не нужны, платить не за что.

**Статус:** этап 2 из 3. Этапы 0–1 (аудио-контур) и 2 (понимание команд и
управление ПК) готовы. Не готов: трей, история диалогов, таймеры и напоминания.

---

## Что уже работает

**Голос:**
- 🎤 Распознавание речи (faster-whisper, локально, GPU если есть)
- 🔇 Определение границ фраз (Silero VAD) — не ждём фиксированные 5 секунд
- 🔊 Синтез речи (Silero TTS v5, 5 русских голосов, ~150 мс на фразу)
- ⌨️ Текстовый ввод как полноценная альтернатива голосу
- 🛑 Прерывание: заговорил — ассистент замолчал

**Интерфейс:**
- 🖥 Значок в трее с индикатором состояния (слушаю / думаю / говорю / пауза)
- 📜 Окно истории с поиском по всем прошлым разговорам
- ⚙️ Окно настроек: микрофон, голос, кнопка активации, модель распознавания
- 🕒 Автозапуск вместе с Windows

**Понимание (35 команд, 9 навыков):**
- ⏰ Время, дата, день недели
- 🚀 Открытие и закрытие программ, файлов, папок
- 🔈 Громкость, mute, медиаплеер
- 📊 Состояние системы: процессор, память, диск, батарея, время работы
- 🖥 Окна: список, переключение, закрытие, свернуть всё
- 📋 Буфер обмена, скриншот, яркость
- ⚡ **Питание — только с голосовым подтверждением**

Не готово: таймеры, напоминания, заметки, погода, поиск (этап v1).

## Какие команды понимает ассистент

Полный справочник — [`docs/КОМАНДЫ.md`](docs/КОМАНДЫ.md).

Для каждой команды там указано:
- **полное имя** (например `apps.open`) — техническое название;
- **что можно сказать** — реальные фразы, которые точно сработают;
- **слоты** — что ассистент должен извлечь из фразы;
- пометка `[ТРЕБУЕТ ПОДТВЕРЖДЕНИЯ]` для опасных действий.

Файл **генерируется из кода**, поэтому не может устареть. Пересоздать:

```powershell
.\run_sinaps.bat commands --out docs\КОМАНДЫ.md
```

Проверить, сработает ли конкретная фраза (ничего не выполняя):

```powershell
.\run_sinaps.bat try "открой блокнот"
```

## Требования

- **Python 3.12** — строго. На 3.13/3.14 нет wheels у `ctranslate2`,
  поэтому `faster-whisper` там просто не установится.
- Windows (протестировано), macOS/Linux — правки в `platform/` появятся на
  этапе 2, аудио-контур кроссплатформенный.
- Микрофон (опционально — работает и без него, через текст).
- Видеокарта (опционально). Без неё STT считает на CPU и работает медленнее.

## Установка

```powershell
cd D:\Sinaps

# 1. Окружение под Python 3.12
py -3.12 -m venv .venv

# 2. Зависимости
.\.venv\Scripts\python -m pip install -r requirements.txt

# 3. Проверка
.\.venv\Scripts\python -m sinaps selftest
```

При первом запуске скачиваются модели (~600 МБ):

| Модель | Размер | Когда нужна |
|---|---|---|
| faster-whisper `small` | ~460 МБ | всегда, при первом распознавании |
| Silero TTS v5 | ~130 МБ | всегда, при первом синтезе |
| Silero VAD | ~2 МБ | сразу |

Если видеокарты нет, удали из `requirements.txt` строки `nvidia-cublas-cu12`
и `nvidia-cudnn-cu12` — будет работать на CPU.

## Запуск

```powershell
.\run_sinaps_silent.bat          # запуск с треем (без консоли) — основной режим
.\run_sinaps.bat                  # обычный запуск (микрофон + консоль, для отладки)
.\run_sinaps.bat selftest         # проверка окружения
.\run_sinaps.bat commands         # список всех команд ассистента
.\run_sinaps.bat try              # проверить понимание фраз (ничего не выполняя)
.\run_sinaps.bat check-mic        # проверить микрофон
.\run_sinaps.bat hotkeys          # проверить клавиши и кнопки мыши
.\run_sinaps.bat evaluate         # сравнить модели STT на записях
.\run_sinaps.bat devices          # список аудиоустройств
.\run_sinaps.bat speak "Привет"    # просто озвучить текст
.\run_sinaps.bat listen           # один цикл: послушать и ответить
.\run_sinaps.bat listen --file tests\fixtures\open_notepad.wav
.\run_sinaps.bat benchmark        # замер задержек на тестовых фразах
.\run_sinaps.bat metrics          # статистика задержек
```

### Режим с треем

`run_sinaps_silent.bat` запускает ассистента без окна консоли. Управление —
значок в области уведомлений:

| Цвет значка | Что происходит |
|---|---|
| серый | микрофон открыт, ждёт активации |
| зелёный | слушает |
| жёлтый | думает |
| синий | говорит |
| красный | ошибка |
| тусклый | пауза |

Меню значка: **Пауза**, **Озвучка ответа**, **История**, **Настройки**,
**Очистить историю**, **Выход**. Двойной клик по значку открывает историю.

> Windows 11 прячет часть значков под стрелкой `^` в трее. Если значок
> Sinaps пропал после установки — перетащи его мышью на панель задач
> обратно, иначе он будет жить под стрелкой.

**История** (`data/history.db`) хранит реплики локально, в SQLite. Срок
хранения задаётся в настройках («Распознавание → Хранить историю, дней»),
по умолчанию 30 дней. Файл можно удалить вручную — это не кэш, а
единственная копия переписок.

**Автозапуск** включается в «Настройки → Распознавание → Запускать вместе
с Windows». Пишется запись в `HKCU\...\CurrentVersion\Run` — без прав
администратора, отключается в «Диспетчере задач → Автозагрузка».

### Проверка понимания без риска

`try` прогоняет фразы через NLU и показывает выбранное намерение и слоты —
**ничего не выполняя**. Незаменимо при добавлении новых команд:

```
фраза                        намерение              слоты
который час                  time.now               -
открой блокнот               apps.open              name=блокнот
выключи компьютер            power.shutdown         - [опасное]
сделай абстрактную фигню     -- не найдено --
```

Свои фразы: `.\run_sinaps.bat try открой блокнот "сделай громче на пять"`

Или напрямую: `.\.venv\Scripts\python -m sinaps --help`

> **Важно про `.bat`:** файлы `run_sinaps.bat` и `run_sinaps_silent.bat`
> намеренно написаны **только латиницей**. `cmd.exe` читает `.bat` в системной
> кодировке (866/1251), а не в UTF-8, поэтому кириллица внутри батника
> разрушает разбор команды: `%ERRORLEVEL%` съедается, `>nul` распадается на
> два символа, и скрипт уходит в бесконечный цикл ошибок «не является
> внутренней или внешней командой». Весь русский текст — внутри Python,
> где кодировка под контролем.

### Голосовой ввод: как будить ассистента

| Действие | Кнопка |
|---|---|
| Открыть окно прослушивания | боковая мышь **«вперёд»** (mouse5) |
| Говори, пока держишь | боковая мышь **«назад»** (mouse4) |
| То же с клавиатуры | `Ctrl+Space` |

После активации — 8 секунд на фразу. Клавиатура работает одновременно с
мышью: если софт мыши съел боковую кнопку, остаётся запасной способ.

Если кнопка не реагирует, проверь перехват отдельно:

```powershell
.\run_sinaps.bat hotkeys --seconds 10
```

Покажет, какие из настроенных кнопок система отдаёт, а какие нет. Подробности
и список причин — [`docs/HOTKEYS.md`](docs/HOTKEYS.md).

### Если голос не захватывается

**Проверь, что запущен только один экземпляр.** Это самая частая причина
«микрофон не работает» после всех настроек.

Две копии Sinaps делят один входной аудиопоток Windows, и речь разрывается на
обрывки. Симптомы узнаваемы: фразы одинаковой длины и одинаковые выдумки в
логе.

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe' OR Name='pythonw.exe'" |
    Select-Object ProcessId, CommandLine
```

Остановить всё:

```powershell
Get-Process python,pythonw -ErrorAction SilentlyContinue | Stop-Process
```

Вторая копия сама откажется запускаться:

```
Sinaps уже запущен (процесс 12345) и держит микрофон.
Две копии делят один входной поток — голос будет обрываться.
```

Не запускай одновременно `run_sinaps.bat` и `run_sinaps_silent.bat`: первая
для работы вручную, вторая — для автозагрузки. Обе вместе держат микрофон.

### Если нет микрофона

Ассистент не падает, а сам переключается в текстовый режим и предупреждает об
этом. Форсировать режим можно явно:

```powershell
.\run_sinaps.bat --text-only
```

## Настройка

`data/config.yaml` создаётся автоматически при первом запуске.
Менять руками нужно редко, но полезно знать главное:

```yaml
stt:
  engine: faster_whisper
  model: small          # tiny | base | small | medium | large-v3-turbo
  device: auto          # auto | cuda | cpu
  language: ru
  min_confidence: 0.25  # ниже — считаем галлюцинацией, не команду
  min_dbfs: -50.0       # тише — в модель не идём

tts:
  engine: silero
  voice: xenia          # xenia | kseniya | baya | aidar | eugene
  speed: 1.0            # 0.5 … 2.0
  volume: 1.0

vad:
  threshold: 0.5        # чувствительность
  silence_ms: 600       # пауза, считающаяся концом фразы

privacy:
  local_only: true      # требование проекта: сеть запрещена
```

**Быстрее распознавание:** поставь `model: medium` (нужна GPU).
**Лучше качество:** `model: large-v3-turbo` (нужна GPU 8+ ГБ).
**Чувствительнее микрофон:** снизь `vad.threshold` до 0.35.

### Если ассистент выдумывает фразы

Whisper на тишине не молчит, а сочиняет правдоподобное — «субтитры»,
«спокойная музыка». Это его устройство, а не ошибка настройки. Защита
измеряется и настраивается:

```yaml
stt:
  min_confidence: 0.25   # живая речь 0.53-0.92, выдумки 0.00-0.06
  min_dbfs: -50.0
```

- Ассистент **не слышит** голос → понизь `min_dbfs` до `-60`.
- Ассистент **слышит, но отвечает «не расслышал»** → понизь `min_confidence` до `0.15`.
- Хочешь увидеть выдумки как есть (для отладки) → `min_dbfs: -120.0`, `min_confidence: 0.0`.

Подробности — `ARCHITECTURE.md`, раздел 10.

## Замеры на этой машине

RTX 4060, Python 3.12, модель `small`, на пяти тестовых фразах:

```
  стадия          n      p50      p95     mean      max
  -----------------------------------------------------
  vad_end         5    4.219    4.672    4.035    4.672   ← конец речи
  stt_done        5    0.313    0.453    0.347    0.453   ← распознавание
  response        5    0.313    0.469    0.350    0.469   ← ЗАДЕРЖКА ОТВЕТА
  total           5    4.625    5.141    4.385    5.141   ← включая речь

Ответ быстрее 1.6 с: 100% диалогов
```

Ключевая метрика — `response`: от конца фразы до первого звука ответа.
`vad_end` и `total` большие только потому, что файл проигрывается в реальном
времени (это не задержка системы, а длительность речи).

Требование проекта «ответ за < 1–2 секунды» выполняется с трёхкратным запасом
ещё до появления этапа 2. Повторить замер: `python -m sinaps benchmark`.

### Как добавить свою команду

Одна декларация — и команда появляется везде: в распознавании, в справке
и в схеме для будущего LLM.

```python
# sinaps/skills/timer.py
def register() -> Skill:
    skill = Skill("timer", description="Таймеры")

    async def set_timer(ctx, slots):
        ctx.reply(f"Ставлю таймер на {slots['duration'].humanize()}")

    skill.command(
        "set", set_timer,
        patterns=[r"поставь таймер на (?P<duration>.+)"],
        examples=["поставь таймер на пять минут"],
        slots={"duration": SlotSpec("duration", "duration")},
        description="Поставить таймер",
    )
    return skill
```

Дальше добавить `registry.add(timer.register())` в
`sinaps/skills/engine.py::build_default_registry`. Проверить:
`python -m sinaps try "поставь таймер на пять минут"`.

## Разработка

Полезные команды:

```powershell
# Подробный лог
.\run_sinaps.bat -v run

# Только синтез, без звука (быстрая проверка TTS)
.\.venv\Scripts\python -m sinaps speak "Тест" --no-play

# Записать 5 секунд с микрофона для отладки STT
.\run_sinaps.bat record data\my_voice.wav --seconds 5

# Прогнать записанный файл через весь контур
.\run_sinaps.bat listen --file data\my_voice.wav
```

Логи: `data/logs/sinaps.log` (отладка), `data/logs/dialogues.log`
(что говорил пользователь — чтобы разбирать «ассистент не понял»).

## Безопасность и приватность

- Микрофон пишется в память, на диск не попадает (пока не включишь
  `privacy.record_audio` вручную).
- Сетевых вызовов нет вообще; это проверяется тестом `test_no_network_imports`.
- Опасные действия (выключение ПК, удаление файлов) на этапе 2 потребуют
  голосового подтверждения.
